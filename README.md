Demichrome

A minimal student productivity app designed to turn your phone into a tool, not a distraction.

📲 Download APK

You can download the latest available build from GitHub Actions.

1. Open the "Actions tab" (https://github.com/uwu-demimask/Demichrome/actions).
2. Select the latest successful Build Demichrome APK workflow.
3. Scroll down to the Artifacts section.
4. Download "Demichrome-debug-apk".
5. Extract the ZIP file and install the APK on your Android device.

Note: An APK will be available only after a workflow successfully builds it and uploads the artifact.
